## 🚀 How to Run the Website

### Option 1: Direct Browser Opening (Zero Setup Required)
Simply double-click or open `index.html` in any web browser (Chrome, Edge, Firefox, Brave, Safari):
```powershell
Start-Process "d:\chhath puja\index.html"
```

### Option 2: Run via Local Python Server
```powershell
cd "d:\chhath puja"
python -m http.server 8080
```
Then open `http://localhost:8080` in your browser.
